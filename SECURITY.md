# Security Policy

## Supported Versions

We actively provide security updates only for latest version.

## Reporting a Vulnerability

**Please do not open a public GitHub issue for security vulnerabilities.**

To report a vulnerability, please use one of the following methods:

1. **GitHub Private Reporting:** Navigate to the "Security" tab of this repository and select "Report a vulnerability." (Recommended)
2. **Email:** Send a detailed report to [janekmusin@proton.me].

### What to include in your report:

- A description of the vulnerability.
- Steps to reproduce the issue (PoC).
- Potential impact if exploited.

## Our Process

Once a report is received:

1. We will acknowledge receipt within 48 hours.
2. We will investigate and confirm the bug.
3. We will work on a fix and notify you once it's ready for testing.
4. We will coordinate a public disclosure date with you.

Thank you for helping keep this project secure!
