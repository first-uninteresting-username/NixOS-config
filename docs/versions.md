# Versions (for funsies)

These informal versions track major changes to repository components. Modules, hosts,
packages, documentation, and CI use the shared v3 registry and ownership contract described
in [modules](modules.md) and [checks](checks.md).

- Modules - v3
- Docs - v3
- CI - v3
- Checks - v3
- Hosts - v3
- Dev setup - v2
- Packages - v3
