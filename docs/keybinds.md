# Keybinds

## Window management

| Keybind             | Action                   |
| ------------------- | ------------------------ |
| Alt + Tab           | Disabled                 |
| Super + Tab         | Switch applications      |
| Super + 1-4         | Switch workspace         |
| Super + Shift + 1-4 | Move window to workspace |
| Super + d           | Show desktop             |
| Super + q           | Close window             |
| Super + g           | Minimize window          |
| Super + f           | Maximize window          |
| Super               | Open workspace overview  |
| Super + Scroll      | Change workspace         |

## Applications

| Keybind        | Action            |
| -------------- | ----------------- |
| Super + Return | Terminal          |
| Super + e      | File manager      |
| Super + Space  | Hexecute launcher |
| Super + b      | Clipboard history |
| Shift + Print  | Screenshot        |
| Super + p      | Lock screen       |

## Input

- Caps Lock is swapped with Escape
- Natural scrolling is used for both mouse and touchpad
